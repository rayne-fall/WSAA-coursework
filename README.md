# WSAA-coursework
A repository containing coursework for the Web Services and Applications module at ATU. This repository contains two Python files, a JSON file and a Jupiter notebook.

## Contents

- [assignment2-carddraw.py](assignment2-carddraw.py): A program which draws cards from a shuffled deck and prints the value and suit of each card.
- [cso.json](cso.json): A file containing hostrical data related to the Exchequer account retrieved from the Central Statistics office.
- [assignment03-cso.ipynb](assignment03-cso.ipynb): A notebook containing a program which retrieves data from the CSO and saves it in a JSON file.
- [assignment04-github.py](assignment04-github.py): A file which imports a private repository, replaces a word and commits the changes.

## Running the programs

The contents of the repository can be run locally using [Anaconda](https://www.anaconda.com/download) and [Visual Studio Code](https://code.visualstudio.com/)
### Running locally

1. Clone the repository.
1. Use Anaconda to set up the virtual environment.
1. Launch Visual Studio Code.
1. Install the modules listed in the [requirements.txt](requirements.txt) file.
1. Run the script/notebook.
